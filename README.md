# Luymin releases

Installers and the auto-update feed for the Luymin desktop app.

Download the latest version from **[Releases → Latest](https://github.com/Rizzo489/luymin-releases/releases/latest)**:

| Computer | File |
|---|---|
| Mac with Apple chip (M1–M4) | `Luymin-<version>-mac-arm64.dmg` |
| Mac with Intel | `Luymin-<version>-mac-x64.dmg` |
| Windows | `Luymin-<version>-win-x64.exe` |
| Linux | `.AppImage` (any distro) or `.deb` (Debian/Ubuntu) |

First install on Mac: drag Luymin to Applications, then right-click → Open once.
After that, Luymin updates itself.
